Running Pi-Hole on old hardware

June 3, 2026 • 1899 words • 9 min
homelab project raspberrypi networking

Introduction

When I first started getting into Raspberry Pi and similar technology, it was with an original Pi Model B that was a spare from a family member. I quickly discovered that it would be immensely limited in project potential and I’d have to buy more advanced models to do bigger projects (which I did end up buying).

At the same time, I knew I wanted to find some use case for this Pi. After I did some research, I learned that installing Pi-Hole would work. Funny enough, I had Pi-Hole as a project idea for a while, as I was researching projects that would be both practical and a good learning experience for security-related fields. As such, it was an easy decision to make that the project for this particular Pi.

If you have an old Pi and are struggling to find a use for it, consider this project and follow along with me!

System Overview

Hardware OS Software
Raspberry Pi Model B, power adapter, SD card (not microSD), ethernet cable or USB wi-fi adapter PiOS Lite Pi-Hole, fastfetch, speedtest-cli, htop, OpenSSH

DIFFICULTY LEVEL: Easy to intermediate

Build process

If your Pi isn’t already in a case and you’d like to put it in one, do that first. You won’t need any of the GPIO pins so it’s safe to put it in an enclosure of some sort.

With a Raspberry Pi Model B like this, it’s crucial to use PiOS Lite. This is the command line version of PiOS. Modern versions of PiOS with a desktop environment simply will not give you a satisfactory experience and you don’t need it for this project. Using Lite ensures you’re giving as much power to Pi-Hole itself rather than wasting resources on features you won’t need. If you’re unfamiliar with how to set up a Raspberry Pi with an operating system, Raspberry Pi themselves have a great video that goes over how to use Raspberry Pi Imager.

Once you have your SD card flashed, slot it into the Pi and get it hooked up into an LCD monitor via HDMI. Power it on by plugging in the power supply. If you aren’t very comfortable with command-line interfaces, don’t worry! Pi Imager handles the majority of the base setup in a graphical interface. After that, it’s all at the command line but it’s not as intimidating as it seems.

From here, your Pi should boot to the command line. Before you go any further, run the following command to ensure that your OS, update mirrors and software are up to date:

sudo apt update && sudo apt upgrade -y

Networking housekeeping

Before you install Pi-Hole, you’ll need to set up a static IP for your Pi. By default, your router will regularly re-assign private IP addresses to devices within your local network, but the Pi-Hole instance needs a steady, unchanging IP to function properly.

To check your Pi’s current private IP, use the ip addr command in the CLI. Depending on how you’re connected to your router, you will either need to look under something like eth0 for ethernet or wlan0 for wi-fi connections.

Note

If you’re using a more recent Pi, such as the Zero 2 W, this step may be different. I didn’t try it on a Zero 2 W but that is a common option for people to host Pi-Hole on.

Your private IP will look something like 192.168.x.x or something else within the private IP ranges for IPv4. You may be familiar with a common gateway IP on routers (192.168.1.1) but not all private IPs are in the 192.168.x.x range. See that linked article and compare it to the IP listed next to inet.

Next, enter your router’s admin panel. For example, https://192.168.1.1. You want to connect with HTTPS to ensure your connection is encrypted; if you don’t, if someone else is on your local network, they can theoretically see whatever password you enter into the admin panel. You’ll likely get a “not secure” warning when you use HTTPS here, but it’s just because your router doesn’t have an SSL certificate assigned to it and your browser is alerting you to that. The encryption still works fine.

Once in the admin panel, you’ll want to look in connection settings for DHCP reservations (might be under a different name). Once in that menu, look for the name and private IP of your Pi. Depending on your router, things might be different but in mine, it was as simple as selecting a checkbox next to the device in the menu and pressing an Add DHCP Reservation button.

Once you’ve done that, ensure your changed setting saved correctly. Don’t close the admin panel yet; you’ll need it once more before the project ends.

Pi-Hole setup

Important

Documenting this project slipped my mind until a while after I had set everything up, so some of the installation steps may be different than what I did, but it should still work fine for you. The Pi-Hole project has fantastic documentation for you to review if you get stuck with something.

The installation process is pretty simple as the Pi-Hole installer will walk you through most of it. The Pi-Hole documentation lists three different ways you can get started but the most advisable way would be through the automated method: curl -sSL https://install.pi-hole.net | bash. I recommend choosing Quad9 as your DNS service, as they’re a privacy-friendly option with built-in malware filtering.

After you make it through the installer, you’ll need to set the Pi-Hole server’s IP address as the primary DNS resolver within your router’s admin panel. This will differ depending on what brand and model your router is but you’ll likely find this setting in the same area that you found the DHCP settings earlier. You’ll want to find a section titled something like “Static DNS”, possibly with four entry fields for the four different octets of an IPv4 address.

For me, I set up my Pi-Hole server as the primary DNS resolver but I also added standard Quad9 and Mullvad Public DNS as fallback options. This is helpful if the Pi-Hole instance goes down for some reason. It has actually saved me a couple times, such as if I unplug the Pi by accident, or if there’s some sort of bug that requires me to reboot the Pi. With a fallback resolver listed, that means you can still access the internet without the Pi, it will just be much slower at resolving domains until you fix the issue with the Pi.

Post-setup

First of all, write down the admin panel password, preferably within a password manager.

On all of my systems, I always install fastfetch or something like it, as it’s incredibly useful for a quick glance at system information. Likewise, you’ll want to have a system resource monitor you’re comfortable. I use btop on most systems due to how powerful and readable it is, but I opted to use htop on this build instead, just to cut down on extra resources as it’s already included with PiOS Lite. Finally, it’d be smart to install Ookla’s speedtest-cli for diagnosing any networking issues you might have with the Pi-Hole server. Use the option labeled “Ubuntu/Debian”, as that’s what PiOS is based off of.

You’re also going to want to have SSH set up for this system. It’s honestly a must-have for the project, as you’re not going to want to hook up a monitor just to run updates and maintenance. Having SSH set up allows you to remotely manage the Pi-Hole server from any other system on your home network. It’s a critical skill for home lab.

You’re going to want to check out the web panel next. You do this by navigating to the IP of the Pi via your web browser, eg. https://192.168.x.x/admin, and log in with the admin password you wrote down earlier. Here, you’ll have access to all sorts of stats, error logging and a graphical way to tweak certain settings. This is also a way you can easily add new blocklists to your Pi-Hole server, which you will probably want to do to better suit your preferences.

Where to find more lists

You can find all sorts of great suggestions by using your favorite search engine or AI to discover lists for the purposes you need. The default block list blocks a good chunk of ads and trackers but you can always add more and make your defenses more robust. For example, I added the Roku nuke list from GitHub user D2007jr and HaGeZi’s Pro blocklist and this combo filters the majority of things. The caveat is that any service that bakes its ads into streams (for example, YouTube, Pluto and some Roku live channels) will still get through, sadly, and I can’t find any way to reliably block those. You can get around YouTube ads via a browser like Brave or a YouTube privacy client, but I can’t find a way to block the ads on the live channels themselves even with a browser such as Brave.

Maintaining the system

I check the web panel and SSH into the server a few times per week just because I like looking at what’s going on, but realistically, you should only need to do that every week or two. You could set up cron jobs to run updates on the server but personally, I get a little dose of satisfaction from running the update commands so I don’t do that. Plus, you don’t want to constantly check for updates because of the limitations of this hardware and its impact on your browsing speeds, so I’d suggest only running updates once per week at a time when the traffic will be minimal.

Keep an eye on the web panel. It doesn’t really give you a massive alert when updates are available to Pi-Hole itself. You’ll want to look at the footer of the page as that’s where I notice the update message.

Minor troubleshooting

  • Because I live with family and nobody knew the router admin password, I had to reset router to gain access.
  • I had to run sudo pihole updateGravity to fix an error -2 code in Domains On Lists. I’m not sure if this is a common error but that command updates your lists so you’ll likely need to use it later as you add more lists to filter.

Final thoughts

Honestly, I feel like this is a project that everyone in tech should try. It’s immensely useful: it boosts your quality of life significantly, especially with how everything is full of intrusive ads nowadays. Not to mention the fact that such a project is a boost to privacy and security, as well! It’s not a super difficult project to do if you’re even slightly tech-savvy, and it will improve things for your entire household.

Not only this but it’s a good way to repurpose an old Raspberry Pi and to learn how to use a Pi in general. You don’t have to use a Pi Model B, you could use a Zero 2 W which I hear a lot of people using for this sort of project, but I’m just writing this to say that it’s completely doable on an old model.

This project is a living example of the real-world impact that Raspberry Pi has had on the world of tech and DIY projects!
